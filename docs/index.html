Topic Phylogeny

What is Topic Phylogeny? Papers are organized in a 4-level hierarchy inspired by biological taxonomy, where broad research areas are progressively subdivided into specific methods and tasks.
Phylum → Class → Order → Genus
Example: Large Language Models → LLM Reasoning → Mathematical & Code Reasoning → Math / Code
Classification is task/domain-first: a paper using diffusion for protein design is tagged as Scientific Applications, not just Generative Models. Each paper receives up to 3 tags from different Phyla.
